# Embroidery Screenshot Studio Pro

Windows app by [Excess Pro Net LLC](https://excesspronet.com) that turns a whole folder of machine embroidery files into listing-quality preview images in one batch — ready for Etsy, Shopify and your own shop pages.

## What it does

- **Reads 40 embroidery formats** — `.pes`, `.dst`, `.jef`, `.vp3`, `.exp`, `.hus`, `.vip`, `.xxx`, `.sew`, `.pec` and more
- **Its own render engine** — threads are drawn as real stitches with a sheen highlight and a soft drop shadow, not a flat line dump
- **Backgrounds** — white, off-white, linen, light grey, charcoal, black, any custom colour, or fully transparent PNG/WEBP
- **Fabric texture** that makes the ground read as cloth
- **Square canvas** for uniform listing thumbnails, or **crop to design** to follow each design's own shape
- **500 – 3000 px** output, adjustable padding, adjustable thread thickness
- **Four anti-aliasing levels** — renders supersampled and scales down for smooth threads
- **PNG, JPG and WEBP** export with a quality slider
- **Live preview** that re-renders as you change any setting, so the batch holds no surprises
- **Design details** — stitch count, stitch blocks, colour changes, size in mm and inches, and the thread palette stored in the file
- **Batch tools** — filename suffix, skip files that already exist, mirror your sub-folder structure
